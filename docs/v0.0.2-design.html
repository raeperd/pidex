Returning to work

A developer opens a project, chooses a saved session, and continues with the right history and unsent text. The primary action is Resume, then Send.

Direction

The current Pidex palette, cyan focus rings, and blue actions. A 256px sidebar keeps sessions close; conversation text stays within 768px. System typography, two weights, three text tones, 8px controls, 16px composition surfaces establish hierarchy. The composer follows main with a 24px radius, a circular blue Send action, a red Stop action, and read-only model and run status.

Behavior and scope

  • Launch shows a centered composer with recent projects in the sidebar. Selecting a project keeps the other projects visible and nests its sessions directly beneath that project. The composer starts a new session; selecting an existing session explicitly opens its history. Sessions are ordered by latest activity.
  • Only one session runs. Navigation is disabled through Running and Stopping. A failed destination load keeps Send disabled until Retry succeeds.
  • Draft labels belong to each session. New sessions get an identity before their first send. Drafts remain editable during a run.
  • The demo stores only sample composer drafts in browser storage. Sending simulates acceptance and a run. Reload returns to recent projects. Native folder selection, Pi history, atomic disk writes, and lifecycle guarantees belong to the implementation.
  • The state picker is a review tool outside the app. It can reset a simulation. No rename, model picker, terminal, file tree, or concurrent agents are proposed.
