# Commit messages and PR titles

Use [Conventional Commits 1.0.0](https://www.conventionalcommits.org/en/v1.0.0/) for new commit messages and PR titles: `<type>[optional scope][!]: <summary>`.

Use `feat` for features, `fix` for bugs, and descriptive types such as `docs`, `refactor`, `test`, `build`, `ci`, or `chore` for other work. Mark breaking changes with `!` or a `BREAKING CHANGE:` footer; use the PR title as the default squash-commit subject.
